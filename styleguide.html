EDS Style Guide

A zero-dependency, drop-in design system for Elementor, WordPress, and any HTML site. Load dist/eds.css in the head and dist/eds.js before </body> — done. Everything on this page is rendered live from those two files.

Colors

Three layers: primitives (--eds-blue-600) feed semantic roles (--eds-primary) which feed component knobs. Build only with semantic roles; rebrand by overriding them. Click any swatch to copy its variable.

Semantic roles (the theming API)

Primitives

Typography

System font stack — zero network requests. The scale is fluid (clamp()): each step grows slightly from mobile to desktop. Override --eds-font-sans to match a brand font.

Spacing

A 4px grid. Use with utilities (eds-stack-4, eds-row-3, eds-mt-6, eds-p-4) or directly as var(--eds-space-N).

Live Theming

The whole system rebrands from a handful of semantic variables. Change them below — every component on this page updates instantly — then copy the generated override block and paste it after eds.css in your project.

Buttons

Base class .eds-btn plus one variant modifier. Real <button> / <a> elements, 44px minimum height, visible focus, press feedback.

Accordion

      
Native <details>/<summary> — content works and stays crawlable without JS. eds.js adds a transform/opacity entrance on open.

      

        

          
FAQ accordion

          

            
            
          

        

        

          

            Does this work without JavaScript?
            
Yes — it's built on native <details>, so content stays accessible and SEO-crawlable even if the script never loads.

          

          

            Can I use it inside Elementor?
            
Yes. Paste the markup into an HTML widget; the stylesheet handles the rest.

          

          

            How do I change the open indicator?
            
The chevron is a CSS-only pseudo-element on the summary — restyle .eds-accordion summary::after.
